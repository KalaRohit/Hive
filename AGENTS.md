# Agent instructions

These rules apply to this directory and its subdirectories.

## 1. Technical English

Use ASD-STE100 Simplified Technical English for all technical text.
This rule includes Markdown files, code comments, documentation, and technical explanations.
Use short sentences, active voice, and consistent technical terms.
Keep code identifiers, file names, commands, and official names unchanged.

## 2. Changes to implementation code

Do not change `.zig` files or other primary implementation code unless the user explicitly requests those changes.
You can read implementation code to understand its operation.
A request to change a specification or documentation does not authorize changes to implementation code.
